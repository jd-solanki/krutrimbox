# Select the agent Model per run and per Agent Action

krutrimbox lets an operator choose the **Model** an Agent Backend runs — the LLM, as distinct from the CLI — through an optional `kb run --model <string>` flag and an optional `model` field on a config `agent` Hook Action, rather than always accepting each backend CLI's auto-picked default. The value is passed through verbatim to the backend's own model flag — `--model <model>`, which both `codex exec` (also spelled `-m`) and `claude -p` accept — inside `buildExecCommand`; a run-level `--model` is the default for the whole Factory Run and a per-step `model` overrides it. Model is orthogonal to the Agent Backend (ADR-0016): a single Agent Backend still serves the entire lifecycle, so a run's Model always belongs to that one backend's namespace.

The flag is deliberately **optional and unvalidated (passthrough)**, unlike the required, allow-listed `--agent`. The two choices are not symmetric: `--agent` is a coarse, high-consequence selection with no sensible default and real output differences the operator wants to compare (ADR-0016), whereas the model has a genuinely good default — the backend vendor ships and maintains their current best model, and model catalogs churn constantly with new snapshots, aliases, and deprecations. Pinning krutrimbox to a hard-coded per-backend allowlist would be stale-maintenance chasing a moving target and would bake one vendor's naming into a backend-agnostic tool, so krutrimbox stays model-agnostic the same way it stays credential-agnostic (auth is delegated wholly to Docker Sandboxes). A mistyped model is safe rather than silent: both backends fail loud — Claude returns a 404 `model_not_found` and exits non-zero, Codex aborts the stream on the same 404 — so a typo can never quietly downgrade the run to a different model. The cost is that validation is **remote**: the bad name is not rejected at launch but after an API round-trip mid-session, surfacing as the existing `KB_R0009` Expected Failure for an AFK run or `KB_R0008` for a hook action.

## Considered Options

- **Cross-backend Agent Actions (e.g. implement with Claude, review with Codex).** Deferred, not adopted. The Target Issue Sandbox is created once per backend from a backend-specific template that has only that one CLI installed (ADR-0007, ADR-0016), so a second backend has no binary to run inside it — cross-backend review needs a second template and sandbox per run, a much larger change than model selection. Varying the Model on the same backend is a one-flag change in the same sandbox and covers the real "review with a stronger/cheaper model" use case.
- **A validated per-backend model allowlist.** Rejected: model catalogs churn faster than krutrimbox releases, an allowlist would be perpetually stale, and each backend CLI already rejects an unknown model loudly. Passthrough keeps krutrimbox out of the business of tracking vendor model names.
- **Make `--model` required, mirroring `--agent`.** Rejected: the "never choose implicitly" reasoning of ADR-0016 is about *which agent*, where there is no good default; the model's vendor default is good and current, so forcing an explicit model on every run only pins operators to strings that go stale.
- **Select the model via the sandbox layer (`sbx` flag or env var).** Rejected: `sbx` has no model concept, and the only env-var route (`ANTHROPIC_MODEL`) exists for Claude but not Codex, so it cannot be a uniform mechanism. The agent argv the run already builds is the single seam that covers both backends.

## Consequences

- `buildExecCommand` gains an optional model parameter per Agent Backend; every other layer (sandbox, checkout, commit, hooks) stays model-agnostic.
- The config schema's `agent` Hook Action gains an optional `model` string; `comment` and `command` actions do not.
- An invalid model is an operator-actionable failure, not a krutrimbox bug — it lands on `KB_R0009` / `KB_R0008` and costs one failed API round-trip before it is reported. A local pre-flight guard remains possible later but is intentionally out of scope.
